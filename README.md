# SusuGH
For managing susu groups in Ghana. BoG Approved :}

## Run the program

```text
go run .
```

The program asks for a member ID, then opens the menu for creating or opening a group.

## Run the tests

```text
go test ./...
```

The tests cover group weeks, member order, partial payments, rejected overpayments, blocked week closing, successful week closing, and reports.
